windows 下同时有 python2 和 3，如何使用。

0x01#

例如我的系统中同时存在 Python2.7 和 Python3.4，那么在命令行模式下输入 Python，默认是执行 Python2.7：

要进入 python3

py -3

即可。

python3 pip 安装模块

py -3 -m pip install [module]
