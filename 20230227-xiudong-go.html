usage#

  • 下载对应 releases 即可

  • 如果你需要手动编译 可以考虑执行以下命令

git clone https://github.com/ronething/xiudong-go.git && cd xiudong-go/cli
make build

具体使用可参考 ./cli 和 ./docs

notice: 此程序更多是学习用途，可以简单分析下自己写 order 命令，祝大家好运~

$ ./showstart
